# P&P & SRO Kompendium v1.27.0

Den almindelige P&P-version kan nu eksportere de markerede resultater til Word eller PDF direkte fra fanen Resultater.

- Vælg filformat og ét niveau for mellemregninger: Ingen, Kort (symbolreferencer), Simpel (numeriske mellemresultater) eller Fuld (udfoldede formler). Kort er standard.
- Rigtig DOCX-pakke med redigerbare Word-ligninger (OMML), A4-layout, overskrifter, opgavenavn, grupper, formelnavne, slutværdier og de valgte enheder.
- PDF downloades direkte og dannes lokalt med læsbar formeltekst. PDF-siderne er billeder; teksten kan ikke markeres eller søges.
- Begge formater følger resultatvisningens grupper og rækkefølge. Beregningen bruger fuld præcision, og slutværdier følger resultatvisningens afrunding og tidsformat.
- Manglende input, manglende referencer og beregningsfejl vises tydeligt. Eksporten beregner igen og bruger aldrig gemte slutværdier.
- Ingen biblioteker fra CDN eller netværkskald. Filnavne og XML-indhold renses.
- Eksamensversionen kan ikke eksportere. SRO har fortsat ingen resultatfane; alle fire offlinefiler genbygges og kontrolleres.
- Tests dækker alle fire niveauer, ZIP/OOXML-struktur, indhold, præcision, enheder, fejl, filnavne og faktiske browserdownloads af begge formater.

# P&P: pyramidestub til firkantede tanke

- Ny figur **Pyramidestub** med rektangulær top og bund samt lodret højde.
- Kan sættes på en kasse og forbindes videre gennem begge ender. Delene samles visuelt i skitse og 3D og deler målene ved samlingen.
- Rumfang, trapezsidernes areal, åbne/lukkede flader og separate pladetykkelser indgår i referencer og tankmasse. Samleflader udelades automatisk.
- Højde, længde og bredde kan isoleres fra rumfanget, også i sammensatte tanke.
- Hx tager højde for stubbens skiftende tværsnit, begge retninger og overgang til næste tankdel.

Vælg **Sammensæt → Kasse → Bund → Ny pyramidestub · Top**, og angiv bundens mål og stubbens højde. Formlerne forudsætter centrerede, parallelle rektangler med rette sider; de håndterer også forskellige længde- og breddeforhold.

Hent `index.html` til normal brug eller `eksamen.html` til eksamensudgaven. Begge fungerer offline. SRO-filerne medfølger fortsat.
